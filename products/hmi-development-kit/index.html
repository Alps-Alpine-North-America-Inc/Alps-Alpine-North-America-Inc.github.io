What's Included

Alps Alpine Valley Development Kit Shared development platform for connecting, configuring, and evaluating the included modules. Resistive Position Sensor Board (RDC9 Variant) Angular position-sensing board populated with the RDC9010007 component. Resistive Position Sensor Board (RD6 Variant) Angular position-sensing board populated with the RD6R1A0008 component. ThumbPointer™ HMI Board (Qwiic) Two-axis ThumbPointer control with integrated push switch and I2C interface. Alps Alpine Haptic Reactor (Heavy type) Heavy type AFR-series haptic reactor for high-force tactile feedback evaluation.
Accessories Qwiic cables, power supply, and other accessories needed to connect and evaluate the bundle.
