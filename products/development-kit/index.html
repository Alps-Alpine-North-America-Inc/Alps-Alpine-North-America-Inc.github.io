Overview

Product Overview

The Alps Alpine Valley Development Kit is a modular evaluation and prototyping platform designed to simplify the testing of Alps Alpine sensor and human-machine interface technologies. By combining a flexible I/O development board with public tools and open-source resources, Valley enables engineers to quickly connect compatible devices, configure operating parameters, and visualize live sensor data through an intuitive graphical interface.

Valley supports a wide range of technologies, including position, magnetic, force, joystick, capacitive-touch, proximity, and haptic solutions. Multiple Qwiic I²C connections make it easy to connect and chain compatible sensor boards, while additional I²C and GPIO connections provide flexibility for evaluating different hardware configurations. The board also includes configurable buttons and LEDs, dual haptic drivers, and USB and Bluetooth communication (Coming Soon) capabilities.

Features & Specs

Features & Specifications

Key Features

  • Modular evaluation platform for Alps Alpine sensor and HMI technologies
  • Live data visualization and device configuration using the PEAK PC application
  • Two chainable Qwiic I²C host connections
  • I²C and GPIO connectivity
  • Two configurable buttons and two configurable LEDs
  • Dual haptic drivers for tactile-feedback development
  • USB and Bluetooth (Coming Soon) host communication
  • Support for evaluating multiple sensors within a single system
