Overview

Product Overview

The Alps Alpine Force Sensor Board (Qwiic) is a packaged board, featuring the Qwiic-style interface, built around the HSFPAR304A component to allow for quick and rapid prototyping.

The HSFPAR304A is a SMD-unit type analog load-detection force sensor with a 0 to 20 N force range, 1.5 to 6 V supply range, and a 200 N max load rating.

Features & Specs

Features & Specifications

Key Features

  • Built around the HSFPAR304A force sensor.
  • SMD-unit type force sensor with a 4.20 × 3.60 × 2.69 mm package.
  • On-board differential instrumentation amplifier for amplifying the force sensor output.
  • 0 to 13 N force range with 2.3 mV/V/N sensitivity (Component Max Force Range 0-20N).
  • 200 N max load rating for higher overload tolerance.
  • High durability rated for 1,000,000 cycles.
