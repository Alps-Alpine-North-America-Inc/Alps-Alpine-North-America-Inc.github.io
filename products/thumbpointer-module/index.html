Overview

Product Overview

The Alps Alpine ThumbPointer™ HMI Board (Qwiic) is a packaged board, featuring the Qwiic-style interface, built around the RKJXV122400R component to allow for quick and rapid prototyping.

The RKJXV122400R is a single-shaft thumb controller with analog directional response and a center push action, making it well suited for menu control, navigation input, and compact user interfaces.

Features & Specs

Features & Specifications

Key Features

  • Built around the RKJXV122400R ThumbPointer™ stick controller.
  • Single-shaft directional input with lever return mechanism.
  • Center push switch integrated into the control element.
  • Component has 10kΩ total resistance with up to 23° operating angle in each direction.
  • High durability with 2,000,000 directional cycles and 500,000 center-push cycles.

Specifications

Core component RKJXV122400R ThumbPointer™
Total resistance 10kΩ
Board Supply voltage 3.3 V
Component Maximum operating voltage 5V DC
Operating angle 23° max. in each direction
Center push Included, 0.4(+0.5, -0.3) mm travel
Directional operating force 14 ±10 mN·m
Push operating force 7.4 ±3 N
Operating life 2,000,000 directional cycles; 500,000 push cycles
