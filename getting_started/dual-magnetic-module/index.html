Introduction

Introduction

The Alps Alpine Dual Switching Magnetic Sensor Board (Qwiic) reports whether a north pole, south pole, or no pole is detected. It communicates over I2C through the Qwiic Connect System and is supported by the SenseKitDualSwitchingMagneticSensor class in the Alps Alpine SenseKit Arduino library.

Board Summary

Hardware Overview

Board Features

Hardware Overview

This board is built around its primary Alps Alpine component and includes supporting features that are important during setup and development. The sections below identify the key board elements, connections, and configuration points to be aware of before bringing the board into your project.

Pins (SWD Programming)

These pins provide Serial Wire Debug (SWD) access for advanced users who need to reflash or modify the firmware running on the board's onboard STM32 microcontroller. They are not required for normal Qwiic operation.

  • 3V3 - 3.3 V power reference for the programming connection.
  • GND - Common ground reference.
  • SWCLK - Serial Wire Debug clock signal.
  • SWDIO - Serial Wire Debug data signal.
  • NRST - Microcontroller reset signal.
Note:

The 3V3 pin is not regulated. Use only a 3.3 V supply; applying a different voltage may damage onboard components. Reflashing or modifying the preinstalled firmware is an advanced operation performed at your own risk and may prevent the board from working with prebuilt tools or demo applications until compatible firmware is restored.

Qwiic Connectors

Each board includes two standard Qwiic connectors that provide power and I2C connectivity. Both connectors share the same bus, allowing compatible Qwiic devices to be daisy chained together.

I2C Jumpers

The two cuttable traces control the board's internal I2C pull-up resistors. By default, each outer pad is bridged to its center pad, enabling pull-ups on the SDA and SCL lines. Cutting the copper trace between an outer pad and its center pad removes the pull-up for that respective I2C line.

I2C Address Pads

Each board supports four assigned I2C addresses, selected with the two solder-jumper pads labeled ADDR1 and ADDR0. The default address is selected out of the box with both pads open. Soldering a pad sets its corresponding binary value to 1, allowing multiple identical boards to share one bus when each uses a different address selection.

ADDR1 ADDR0 Address Selection
00Default
01Alternate 1
10Alternate 2
11Alternate 3

Power LED

Each board includes a red power-indicator LED that illuminates when the 3.3 V rail is powered. Use it as a quick confirmation that the board is receiving power before continuing with I2C communication or software setup.

Software Setup & Programming

Note:

This code/library has been written and tested on Arduino IDE version 2.3.10.

If this is your first time using Arduino, please review our tutorial on installing the Arduino IDE. If you have not previously installed an Arduino library, please check out our installation guide.

Install this repository as an Arduino library, then open File > Examples > Alps Alpine SenseKit > DualSwitchingMagneticSensor. Select your board and serial port, upload the sketch, and open Serial Monitor at 9600 baud. The example starts by calling begin() and isConnected(). It prints formatted pole detection as well as the two raw switch states.

Check GitHub Repository

Arduino Library Functions

Below is a list of the functions that can be used with the Dual Switching Magnetic Sensor Board (Qwiic), along with a description of what each function does and how to use it.

Function Description
begin() Initializes the selected I2C bus.
isConnected() Confirms that the expected sensor board responds.
getFormattedValues(&pole) Reads NoPoleDetected, SouthPoleDetected, or NorthPoleDetected.
getRawValues(&values) Reads the individual south and north switch outputs.
getDetectedMagneticPole() Returns the formatted pole value directly.

Raw switch outputs are active-low: SwitchDetected (0) means that switch detects its corresponding pole; SwitchNotDetected (1) means it does not. Always check the bool result of getFormattedValues() or getRawValues() before using the output.

To select a non-default address or I2C bus, pass them to the constructor.

SenseKitDualSwitchingMagneticSensor sensor(
  SenseKitDualSwitchingMagneticSensor::AlternateI2CAddress1, Wire1);

If you wish to use or learn the I2C message formats directly, you can follow the document below.

Reference

Example Code

#include <AlpsAlpineSenseKit.h>

SenseKitDualSwitchingMagneticSensor sensor;

void setup() {
  Serial.begin(9600);
  delay(1000);
  sensor.begin();

  if (!sensor.isConnected()) {
    Serial.println("Dual Switching Magnetic Sensor not found.");
    while (true) {}
  }
}

void loop() {
  SenseKitDualSwitchingMagneticSensor::DetectedMagneticPole pole;
  if (sensor.getFormattedValues(&pole)) {
    if (pole == SenseKitDualSwitchingMagneticSensor::SouthPoleDetected) {
      Serial.println("South pole detected");
    } else if (pole == SenseKitDualSwitchingMagneticSensor::NorthPoleDetected) {
      Serial.println("North pole detected");
    } else {
      Serial.println("No pole detected");
    }
  }
  delay(500);
}

Troubleshooting

  • If isConnected() fails, check the Qwiic cable orientation, power, SDA, and SCL connections, then verify the selected I2C address.
  • If a pole is not detected, move the magnet closer and test the opposite magnet face. Magnetic-field strength and orientation affect the result.
  • If raw switch states look reversed, remember they are active-low.
