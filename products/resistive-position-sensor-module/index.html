Overview

Product Overview

The Alps Alpine Resistive Position Sensor Board (Qwiic) is a packaged board, featuring the Qwiic-style interface, built around either the RDC9010007 or RD6R1A0008 component to allow for quick and rapid prototyping.

The RDC9010007 (populated on Variant RDC9) supports compact long-life rotary sensing, while the RD6R1A0008 (populated on Variant RD6) supports a connector-type rotary sensor option with a wider effective electrical range.

-*Only one resistive position sensor variant is populated on a board at a time.

Features & Specs

Features & Specifications

Alps Alpine RDC9010007

RDC9010007 (RDC9) Variant

Compact rotary sensor option for long-life angular sensing on the U2 footprint.

Key Features

  • Uses the Alps Alpine RDC9010007 compact rotary position sensor.
  • 10kΩ total resistance with a 260° effective electrical range.
  • ±3% linearity across a 244° linearity guarantee range.
  • Long-life design rated for 10,000,000 cycles.
  • Automotive-oriented RDC90 sensor family for positioning applications.

Alps Alpine RD6R1A0008

RD6R1A0008 (RD6) Variant

Connector-type rotary sensor option for the U3 footprint with a wider effective electrical range.

Key Features

  • Uses the Alps Alpine RD6R1A0008 Rotary Type RD6R1A Series sensor.
  • Connector-type mounting style with φ3.53 hollow shaft variation.
  • 3.8kΩ total resistance with a 320° effective electrical range.
  • ±2% linearity across a 310° linearity guarantee range.
  • Automotive standard product with 500,000-cycle operating life.
