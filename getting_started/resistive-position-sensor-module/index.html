Introduction

Introduction

The Alps Alpine Resistive Position Sensor Board (Qwiic) reports angular position. It communicates over I2C through the Qwiic Connect System and is supported by the SenseKitResistivePositionSensor class in the Alps Alpine SenseKit Arduino library. The class supports both board population variants: RDC9 reports 0-260 degrees and RD6 reports 0-320 degrees.

Hardware Overview

Board Features

Hardware Overview

This board is built around its primary Alps Alpine component and includes supporting features that are important during setup and development. The sections below identify the key board elements, connections, and configuration points to be aware of before bringing the board into your project.

Pins (SWD Programming)

These pins provide Serial Wire Debug (SWD) access for advanced users who need to reflash or modify the firmware running on the board's onboard STM32 microcontroller. They are not required for normal Qwiic operation.

  • 3V3 - 3.3 V power reference for the programming connection.
  • GND - Common ground reference.
  • SWCLK - Serial Wire Debug clock signal.
  • SWDIO - Serial Wire Debug data signal.
  • NRST - Microcontroller reset signal.
Note:

The 3V3 pin is not regulated. Use only a 3.3 V supply; applying a different voltage may damage onboard components. Reflashing or modifying the preinstalled firmware is an advanced operation performed at your own risk and may prevent the board from working with prebuilt tools or demo applications until compatible firmware is restored.

Qwiic Connectors

Each board includes two standard Qwiic connectors that provide power and I2C connectivity. Both connectors share the same bus, allowing compatible Qwiic devices to be daisy chained together.

I2C Jumpers

The two cuttable traces control the board's internal I2C pull-up resistors. By default, each outer pad is bridged to its center pad, enabling pull-ups on the SDA and SCL lines. Cutting the copper trace between an outer pad and its center pad removes the pull-up for that respective I2C line.

I2C Address Pads

Each board supports four assigned I2C addresses, selected with the two solder-jumper pads labeled ADDR1 and ADDR0. The default address is selected out of the box with both pads open. Soldering a pad sets its corresponding binary value to 1, allowing multiple identical boards to share one bus when each uses a different address selection.

ADDR1 ADDR0 Address Selection
00Default
01Alternate 1
10Alternate 2
11Alternate 3

Power LED

Each board includes a red power-indicator LED that illuminates when the 3.3 V rail is powered. Use it as a quick confirmation that the board is receiving power before continuing with I2C communication or software setup.

Software Setup & Programming

Note:

This code/library has been written and tested on Arduino IDE version 2.3.10.

If this is your first time using Arduino, please review our tutorial on installing the Arduino IDE. If you have not previously installed an Arduino library, please check out our installation guide.

Install this repository as an Arduino library, then open File > Examples > Alps Alpine SenseKit > ResistivePositionSensorVariantA for the RDC9 board population or ResistivePositionSensorVariantB for the RD6 board population. Select your board and serial port, upload the sketch, and open Serial Monitor at 9600 baud.

Both examples start by calling begin() and isConnected(). They print the formatted angle and raw 12-bit position reading, then show the raw-to-angle conversion for their fitted variant. The RDC9 example demonstrates the 0-260 degree range; the RD6 example demonstrates the 0-320 degree range. The shortened sketch below shows the formatted-reading path for RDC9.

Arduino Library Functions

Below is a list of the functions that can be used with the Resistive Position Sensor Board (Qwiic), along with a description of what each function does and how to use it.

Function Description
getFormattedValues(&angleDegrees) Reads the board-calculated angle in whole degrees.
getRawValues(&position) Reads the 12-bit raw position value, 0-4095.
getAngle() Returns the formatted angle directly.
getRawPosition() Returns the raw position directly.
getVariant() Returns the variant configured in the constructor.

The raw reading can be converted to an approximate angle.

float angleA = rawPosition / 4095.0f * 260.0f;
float angleB = rawPosition / 4095.0f * 320.0f;

Check the Boolean result of getFormattedValues() and getRawValues() before using their output. Readings outside the component’s normal mechanical travel can be unexpected.

For the RD6 board population, construct the class with SenseKitResistivePositionSensor::VariantB instead. To use a non-default address, supply the variant and address.

SenseKitResistivePositionSensor sensor(
  SenseKitResistivePositionSensor::VariantB,
  SenseKitResistivePositionSensor::VariantBAlternateI2CAddress1);

Reference

Example Code

#include <AlpsAlpineSenseKit.h>

SenseKitResistivePositionSensor sensor(
  SenseKitResistivePositionSensor::VariantA);

void setup() {
  Serial.begin(9600);
  delay(1000);
  sensor.begin();

  if (!sensor.isConnected()) {
    Serial.println("Resistive Position Sensor not found.");
    while (true) {}
  }
}

void loop() {
  uint16_t angleDegrees;
  if (sensor.getFormattedValues(&angleDegrees)) {
    Serial.print("Angle (degrees): ");
    Serial.println(angleDegrees);
  }
  delay(500);
}

Support

Troubleshooting

  • If isConnected() fails, check the cable, I2C wiring, power, selected board population, and address.
  • If the angle range is wrong, confirm that the selected RDC9 or RD6 board population matches the fitted board.
  • If readings are erratic, inspect the mechanical coupling and keep the actuator within its specified travel.
